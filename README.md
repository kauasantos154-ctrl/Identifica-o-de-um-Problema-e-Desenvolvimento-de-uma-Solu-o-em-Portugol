# Identifica-o-de-um-Problema-e-Desenvolvimento-de-uma-Solu-o-em-Portugol
Sistema de vendas de uma livraria

1. Qual é o problema identificado? falta de separação de categoria de itens
2. Onde esse problema acontece? Sites de venda 
3. Quem é afetado por ele? cliente
4. Como um programa de computador poderia ajudar a resolver ou minimizar esse
problema? ajudar a separar livros por diversas categorias


● Nome do programa: Kauã Lima Santos
● Objetivo do programa: separar livros por categoria
● Quais informações serão digitadas pelo usuário: opção da categoria se opção = 1 o sistema perguntara quantos dias o cliente deseja alugar o livro se opção == 2 o programa so ira mostrar o preco total.
● Quais informações serão exibidas pelo programa: preco_total, opção do livro e a quantidade de dias desejado 
● Quais regras de negócio serão utilizadas: proibido opções ivalidas  ou algum livro que não esteja no estoque
